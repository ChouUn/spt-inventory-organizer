# tag 规则语法

> Parent: [../index.md](../index.md)
> Related: [../requirements.md](../requirements.md)（F1、F5、F6）
> Status: 目标契约，尚未实现

## 概述

玩家在游戏的编辑 tag 窗口里给容器写整理规则。保存时立即看到解析结果或错误提示；
一键整理时，物品按这些规则被收进容器。

tag 文本由自由文本和零到多条规则组成。自由文本是容器的可读名字，不参与解析。

## 范围

包含：规则的词法与语法、原子的匹配语义、优先级语义、错误与提示、tag 长度上限。

不包含：收纳过程本身，例如哪些物品是候选、容器是否接受、锁如何处理，
见需求 F1 与 F4。不包含 FiR 条件，原始需求未提出。

## 行为契约

### 规则形态

```text
@o[#<order>] [<expr>;]
```

| 写法 | 含义 |
| --- | --- |
| `@o` | 兜底：容器自身过滤允许的全部物品 |
| `@o;` | 同上 |
| `@o#3`、`@o#3;` | 兜底，优先级 3 |
| `@o <expr>;` | 匹配 `<expr>` 的物品 |
| `@o#1 <expr>;` | 匹配 `<expr>` 的物品，优先级 1 |

- 规则头只识别小写 `@o`。
- `#` 紧跟 `@o`，`<order>` 是一位以上的十进制数字。
- 规则头后若跟表达式，二者之间至少一个空白。
- 裸规则的头之后只能是空白、`;`、文本结尾或下一条规则；跟其他文本即视为表达式。
- 表达式必须以 `;` 闭合。从规则头之后到 `;` 之间的全部文本都属于表达式，
  其中不得再出现 `@o`。
- 一个 tag 可以写多条规则，规则之间可以夹任意自由文本。

### 表达式

```text
expr   := term ('||' term)*
term   := factor ('&&' factor)*
factor := '!' factor | atom
atom   := 'n:' <text> | <text>
```

- `&&` 优先级高于 `||`，没有括号。
- `!` 只在一个 factor 的开头被识别，作用于紧随的原子。
- `<text>` 是到下一个 `&&`、`||`、`;` 之前的全部字符，去掉首尾空白。
  单个 `&`、单个 `|`、`(`、`)`、`#`，以及不在开头的 `!`，都是普通字符。
- `<text>` 去空白后为空是错误。

### 原子语义

| 原子 | 匹配条件 |
| --- | --- |
| `<category>` | 物品类别链中任一级的显示名与之相等，忽略大小写 |
| `n:<name>` | 物品显示名或短名包含该字串，忽略大小写 |

- 类别链指物品在手册中的类别及其全部上级类别。
- 显示名、短名、类别名都用玩家当前游戏语言的本地化文本。

### 优先级

- 所有容器的所有规则统一按 `<order>` 升序执行，数字小的先。
- 没写 `<order>` 的规则排在所有带 `<order>` 的规则之后。
- `<order>` 相同、或同为未写的规则之间，先后不作保证。
- 一个物品被先执行的规则收走后，后续规则不再考虑它。

### 错误

保存 tag 时解析。任一规则有错，该 tag 的全部规则都不参与整理，并提示错误。
提示必须包含出错的规则序号和出错位置附近的原文。

| 情况 | 例子 |
| --- | --- |
| 表达式未闭合，包括闭合前又出现 `@o` | `@o ammo`、`@o ammo @o meds;` |
| 条件为空 | `@o ammo\|\|;`、`@o &&ammo;` |
| 名称为空 | `@o n:;`、`@o n: ;` |
| `#` 后不是数字 | `@o#a ammo;`、`@o# ammo;` |
| 规则头后缺少空白 | `@oammo;` |

### 成功提示

保存无错时，按执行顺序逐条用人可读的文字复述规则：优先级，以及条件的含义。
兜底规则标明为兜底。

### 长度上限

tag 输入框接受至少 256 个字符。游戏原生上限是 16。

## 示例

类别名按玩家的游戏语言书写，下表以英文类别为例。

| tag | 效果 |
| --- | --- |
| `弹药 @o#1 n:5.45; @o#5 ammo;` | 名字「弹药」；先收名称含 5.45 的，再兜底收弹药类 |
| `@o ammo&&!n:5.45;` | 弹药类，但排除名称含 5.45 的 |
| `@o medications\|\|n:grenade;` | 医疗类，或名称含 grenade |
| `@o n:ak&&n:74\|\|magazines;` | 名称同时含 ak 与 74，或弹匣类 |
| `杂物 @o` | 名字「杂物」的兜底容器 |
| `@o ammo` | 错误：第 1 条规则未闭合 |
