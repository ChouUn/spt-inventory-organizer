# 等价物品排布与身份映射

> Parent: [../index.md](../index.md)
> Status: 实现与离线验证完成，待游戏内验收（2026-09-10）
> 依据：[排布契约](../feats/packing.md)

## 目标与范围

求解器消除等价物品的身份排列，结果映射回真实库存时尽量不移动原位物品。
本轮覆盖单网格与联合多网格排布、必留和可选物品、限时保底及缓存返回。
保持现有空间与类别目标，沿用预算；不改库存事件或 UIFixes 配置。

## 实现方案

以模板、实际尺寸、完整类别链及各网格的可进入/必留状态建立等价组。
真实 ID 只用于记录来源、映射结果与提交；排布输入改为组内匿名位置槽。
同组位置槽按网格、行列顺序约束，未选位置槽排在末尾，消除身份排列对称性。
同组顺序沿用初始布局的位置顺序，避免提示与约束冲突；
保留输入中的模型变量次序，避免整体排序改变限时搜索路径。
大件与单格仍各有匿名位置槽，但同组交换身份的排列由顺序约束排除。
单网格空间目标锁定后，把已有安全跨度下界加入各层求解，支持逐层证明。

得到位置集合后先匹配可以保持原网格、坐标及转置的真实物品，
再分配其余位置；保留相同模板，不能跨过滤条件或必留约束交换。
不把减少实际移动作为高于空间或类别的求解目标。

## 离线验证结果

沿用调研中的六份快照，各档三次，共 144 次结果检查。
面积、高度、必留物品及层级跨度保持；固定障碍无重叠、无越界。
1 秒预算的实耗中位数如下；移动数为映射后的真实 ID 坐标/转置变化数。

| 请求 | 里程碑移动数 | 本轮移动数 | 本轮跨度 | 本轮耗时 |
| --- | ---: | ---: | --- | ---: |
| 仓库，整理前 | 282 | 267 | [59,124,40,21] | 1012 ms |
| 垃圾箱，整理前 | 96 | 94 | [8,10] | 1004 ms |
| 武器箱 | 0 | 0 | [9,18]，最优 | 153 ms |
| 弹药箱 | 0 | 0 | [6,6]，界限退出 | 2 ms |

仓库与垃圾箱仍会耗满预算，不能把本轮称作整体等待问题已解决。
武器箱前轮同快照中位数约 204 毫秒；本轮局部提速同时包含下界约束的作用，
不能把全部收益单独归因于身份处理。
另从 `28cafab` 导出源码独立构建复跑三次，武器箱中位数约 212 毫秒，
原始输出保留于 `.temp/performance-milestone/weapons-results.tsv`。
垃圾箱 250 毫秒预算三次均维持 [8,10]；整理后的仓库与垃圾箱均无额外移动。
缓存命中仍在毫秒以下。少提交 17 件物品的游戏内实际耗时收益尚未测量。

同组原位匹配覆盖原位、转置、候选、跨网格与不同父类/模板的边界。
小规模穷举对照保持空间及父子目标；新增匿名垃圾箱夹具防止模型重排后质量退步。
完整构建零警告、零错误；Core 145 项及 UIFixes 兼容 4 项测试全部通过。
